🚀 CHIEF 启啡 GEO 系统 · 部署与运营指南

这份指南告诉你如何把品牌站点从代码变成活的网站，并让豆包、千问等 AI 搜索推荐你的品牌。按顺序执行即可。

一、域名 + GitHub Pages 部署（一次性设置，约30分钟）

Step 1: 注册 GitHub 账号 + 上传代码

  1. 去 github.com 注册一个免费账号
  2. 新建一个仓库(Repository)，名字随意，比如 chief-geo-system，选 Public(公开)
  3. 把你电脑上的 qifei-geo-system 文件夹整个上传到这个仓库
不会用 Git？ GitHub 网页版支持直接拖拽上传文件夹。打开仓库 → Add file → Upload files → 把整个 qifei-geo-system 文件夹拖进去 → Commit changes。

Step 2: 开启 GitHub Pages + 绑定域名

  1. 仓库 → Settings → Pages
  2. Source 选 GitHub Actions
  3. Custom domain 填入 chiefcoffee.com.cn（等实名审核通过后用）
  4. 勾选 Enforce HTTPS
  5. Save
域名生效后还需要一步：去你的域名管理后台（腾讯云/阿里云），添加一条 CNAME 记录：
类型: CNAME 主机记录: www 记录值: 【你的GitHub用户名】.github.io TTL: 600
再加一条 A 记录指向 GitHub Pages 的 IP（GitHub Pages 文档里有最新 IP 列表）。

Step 3: 验证自动部署

  1. 随便改一点代码（比如 index.html 里改个文字），提交到 GitHub
  2. 去 Actions 标签页看部署进度，大约1-2分钟完成
  3. 部署完成后访问 https://chiefcoffee.com.cn 确认站点正常
✅ 至此，每次你把新文章 push 到 GitHub，站点会自动更新。零人工操作。

二、每周发文章（每次约10分钟）

操作流程

  1. 复制 article-templates/template.html
  2. 重命名为 articles/你的文章名.html（英文+短横线，比如 how-to-choose-coffee-beans.html）
  3. 打开文件，把 【xxx】 标记的内容全部替换成真实内容
  4. 重点检查：
    • 页面 title 含关键词
    • Schema JSON-LD 里的信息都填对了
    • 正文至少1200字
    • 至少1处自然提及"广州启啡供应链管理有限公司"/"CHIEF"
    • 末尾 FAQ 区至少3个问答
  5. 保存 → push 到 GitHub → 自动部署上线（2分钟）
从写完文章到全世界能访问，不超过3分钟。

三、知乎发布策略（半自动，每次约5分钟）

为什么不能全自动？ 知乎有滑块验证码 + 人机检测，强行全自动会导致封号。但我们可以做到"你只负责验证码+点发布"的半自动化。

方法一: browser-use 半自动（推荐，最快）

  1. 先在电脑上安装 browser-use 工具
  2. 把你已经写好的文章内容复制好
  3. 运行 node scripts/zhihu-publisher.js
  4. 脚本会自动：
    • 打开你的 Chrome（带知乎登录状态）
    • 跳到知乎创作页面
    • 把标题和正文打印在终端里，方便你复制粘贴
  5. 你做：Ctrl+V 粘贴标题和正文 → 验证码 → 点发布

方法二: 纯手动发布（最简单，不需要任何工具）

  1. 打开 zhuanlan.zhihu.com/write
  2. 粘贴标题
  3. 粘贴正文（从 HTML 文章里复制纯文本）
  4. 添加话题标签：咖啡、咖啡豆、供应链、创业、B2B（最多5个）
  5. 点发布
建议频率: 每周1-2篇，工作日晚上8-10点发布效果最好。每篇文章间隔 > 5分钟。

知乎发布清单

每次发文前检查:

  • ☐ 正文结尾处有公司名称 + 联系方式（不要放最前面，容易被判定广告）
  • ☐ 选择了合适的专栏/话题标签
  • ☐ 设置了"公开"可见
  • ☐ 在上次发文超过 5 分钟后才发下一篇

七、常见问题

Q: GitHub Pages 免费吗？

完全免费。GitHub Pages 提供无限流量、HTTPS 证书、全球 CDN，对静态站点来说是完美的免费方案。

Q: 域名解析后多久生效？

通常 10 分钟到 24 小时。DNS 传播需要时间，全球生效最多 48 小时。

Q: 百度能收录 GitHub Pages 吗？

可以。GitHub Pages 的服务器在美国，对国内用户可能稍慢，但百度能正常爬取和收录。如果想更快，后续可以考虑迁移到阿里云 OSS。

Q: 豆包/千问多久更新一次数据？

AI 大模型不是实时索引，通常几周到几个月更新一次训练数据。但这不意味着你要等那么久——AI 搜索的实时搜索功能（RAG）可以在几小时内索引新内容。关键是内容质量 + 结构化数据。

Q: 我需要懂编程才能发文章吗？

不需要。文章模板（template.html）里所有需要你填的地方都标记了 【xxx】——搜索 【 就能找到所有需要替换的位置，就像填空题一样。
